# Typhoon

用于 _明日方舟_ 的PC端预录制工具。游戏在我的电脑上经常未知理由闪退，但是客服一定要求我提供闪退录屏，因为反作弊原因Nvidia App无法直接录制，所以诞生此奇异搞笑玩具

似乎只有我一个人这样？

## 功能

游戏启动后自动开始录制，保存最近30秒的画面和声音，当游戏进程结束时自动保存视频和音频文件，并尝试使用ffmpeg合并音视频。

## 使用方法

1. 安装FFmpeg并添加到系统PATH中
2. 按照`main.py`安装所需的Python依赖
3. 准备好5G以上的内存来存储预录制的画面和声音
4. 运行程序和启动游戏的顺序无所谓，玩一半想起来了再打开也可以

## 注意事项

- 如果音频系统无法锁定回环，需要去windows的音频设置找到`立体声混音 (Stereo Mix)`设备并启用它
- 我的电脑有64G内存所以无所谓，请务必确保你的电脑有足够的内存来存储预录制的画面和声音，我确实没有测试过内存不足的情况会发生什么
